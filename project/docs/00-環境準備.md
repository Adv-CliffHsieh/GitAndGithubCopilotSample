# Phase 0 — 環境準備

## 本階段目標

- 安裝並確認所有工具可用
- 啟動專案，看到 Todo App 畫面
- 認識 Copilot 的三種模式與 `copilot-instructions.md`

## 教學重點

> Copilot agent mode 基本操作、專案級 instructions 檔案的作用

---

## Step 1：安裝工具

確認以下工具已安裝：

| 工具 | 版本需求 | 確認指令 |
|------|---------|---------|
| Node.js | 20 以上 | `node -v` |
| Git | 任意 | `git --version` |
| VS Code | 最新版 | — |

VS Code 擴充功能（左側 Extensions 搜尋安裝）：

- **GitHub Copilot**
- **GitHub Copilot Chat**

安裝後點左下角帳號圖示登入 GitHub，確認 Copilot 已啟用。

## Step 2：取得專案並安裝依賴

```bash
git clone <本專案 repo URL>
cd project
npm install
```

## Step 3：啟動並確認

```bash
npm start
```

打開瀏覽器 <http://localhost:3000>，應看到「待辦事項」頁面。
新增一筆 todo 確認可以運作（**先別測刪除**，那是 Phase 5 的彩蛋）。

再跑一次測試：

```bash
npm test
```

應看到全部測試通過（7 passed）。

## Step 4：認識 Copilot Chat 的三種模式

打開 Copilot Chat（`Cmd+Ctrl+I` 或右上角 Chat 圖示），左下角可切換模式：

| 模式 | 用途 | 本課程使用時機 |
|------|------|--------------|
| **Ask** | 問問題，不改程式碼 | 理解程式碼 |
| **Plan** | 針對問題進行規劃 | 規劃任務 |
| **Agent** | 自主多步驟：讀檔、改檔、跑指令 | 課程主力 |

切到 **Ask** 模式，貼上第一個 prompt 試試：

```text
請幫我導覽這個專案：說明資料夾結構、後端 API 有哪些 endpoint、前端如何呼叫它們。
```

## Step 5：認識 copilot-instructions.md

打開 [.github/copilot-instructions.md](../.github/copilot-instructions.md)，這個檔案會**自動**附加到每一次 Copilot 對話的上下文中。

在 Agent 模式輸入：

```text
這個專案的程式碼慣例是什麼？SQL 可以用字串拼接嗎？
```

Copilot 會依 instructions 回答「禁止字串拼接、必須用 prepared statement」——它並沒有讀你的心，是讀了 instructions 檔。

## 常見問題

**Q：`npm install` 時 better-sqlite3 編譯失敗？**
A：better-sqlite3 需要編譯原生模組。macOS 請先裝 Xcode Command Line Tools（`xcode-select --install`）；Windows 請確認 Node.js 安裝時有勾選 build tools。

**Q：Copilot Chat 沒有 Agent 模式？**
A：更新 VS Code 與 Copilot 擴充到最新版，並確認訂閱方案支援 agent mode。

**Q：port 3000 被其他服務佔用？**
A：改用其他 port 啟動：`PORT=3100 npm start`，之後所有 `localhost:3000` 都換成你的 port。
